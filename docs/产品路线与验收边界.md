# CloudBox 产品路线与验收边界

> 本文沉淀产品设计讨论中的已确认结论，用于指导后续实现和验收。
>
> 文中的「已完成」仅指当前基线能力；「待实现」是已确认的产品方向，不应在界面或 README 中当作现有能力宣传。

## 1. 产品定位

CloudBox 是面向个人及受邀朋友使用的轻量媒体网盘，用于存储照片、视频和一般文件，并通过受控链接分享内容。

产品优先保证以下体验：

- 每个注册用户拥有独立账号、逻辑容量和分享链接。
- 文件以个人存储和受控分享为核心，不以多人实时协作为目标。
- 手机端优先支持浏览与上传；桌面端优先支持文件管理。
- 后端通过应用服务、关系数据库和对象存储分层，后续可以接入企业提供的 S3 兼容对象存储。

当前阶段不承诺把 CloudBox 作为可靠备份服务。只有完成异地副本、备份策略和恢复演练后，才能对外宣称具备备份能力。

## 2. 已完成基线

当前仓库已具备下列基础能力：

| 范围 | 当前基线 |
| --- | --- |
| 账户与文件 | 邀请码注册、登录、JWT 会话鉴权、用户隔离、容量统计、文件与文件夹管理、回收站和预计清理日期。 |
| 上传与存储 | 普通上传、分片上传、分片合并、内容去重，以及本地磁盘或 MinIO 对象存储。 |
| 分享 | 单文件和多文件合并分享、创建、撤销、公开预览、登录下载和保存副本；可设置密码、过期时间和下载次数限制。公开访问具备匿名审计、密码错误锁定和下载频率限制。 |
| 文件处理 | 持久化后台任务、文件校验、缩略图和可选病毒扫描。 |
| Web 工作台 | 邀请注册、强制修改临时密码、文件浏览和搜索筛选、文件夹操作、普通/分片上传与续传、回收站、分享链接、容量展示、管理员控制台、桌面文件表格和移动端媒体网格。 |
| 媒体访问 | JPEG、PNG、WebP 缩略图与图片预览；文件处理状态；视频和 HEIC 的受限访问提示。 |

M1 至 M5 的验收范围均已实现。管理员白名单注册、视频首帧、EXIF 副本脱敏、多实例限速共享和备份恢复演练仍属于后续方向，不应作为当前能力宣传。

## 3. 已确认的产品规则

### 3.1 分享与访问

- 分享链接默认无密码、有效期为 7 天、下载次数不限；创建时可进入高级设置，配置密码、有效期、下载次数和撤销。
- 分享列表应展示文件名称、类型、大小、缩略图或占位图、状态和分享设置，不能只展示 token。
- 链接可被转发。没有密码的公开链接允许直接访问；有密码的链接在密码验证成功前不得展示文件名称、缩略图或其他文件信息。
- 未登录访问者在通过密码验证后可以预览图片。视频第一阶段只展示文件信息和封面，不提供在线播放。
- 下载文件或保存到「我的文件」必须登录。登录后应自动继续原操作，并允许选择是否同时保存一份到自己的文件空间。
- 图片预览不计入下载次数；实际下载和保存到「我的文件」计入下载次数。
- 保存后的文件属于目标用户，计入目标用户的逻辑容量。源文件删除或分享撤销后，已保存副本仍保留；物理对象只在所有用户文件记录均删除后清理。
- 删除源文件时，默认勾选「同时撤销全部分享链接」，并允许所有者明确选择保留。回收站保留期结束后必须撤销关联分享。
- 多文件合并分享至少包含两个文件，共用一个密码、有效期和下载额度。任意源文件进入回收站后，合并链接立即失效，不能保留不完整集合。

### 3.2 账户、邀请与管理员

- 首期注册采用邀请码；后续补充管理员白名单注册。
- 邀请码默认单次使用、有效期 7 天、可撤销，并且只在创建时展示一次；首期不绑定邮箱。
- 初始用户容量为 `1 GB`。管理员可以调整为 `1 GB`、`5 GB`、`10 GB` 等明确档位。
- 系统区分普通用户和管理员。首位管理员由 `ADMIN_USERNAME` 初始化，权限校验必须在后端执行。
- 管理员可管理邀请码、用户状态和容量，并可禁用账号、重置密码或撤销某个用户的全部分享。
- 管理员默认不能浏览用户私有文件内容。权限提升和审计能力需要另行设计，不能以管理身份默认越权。
- 密码重置使用临时密码，并要求用户在下次登录后修改；重置操作应使旧会话失效。

### 3.3 媒体体验

- 桌面端以文件表格和文件管理为主；移动端以媒体网格和快速上传为主。
- 移动端主导航固定为「文件」「分享」「回收站」「我的」。
- JPEG、PNG 和 WebP 提供缩略图与图片预览；HEIC 可以上传、分享和下载，但首期明确提示浏览器不支持预览。
- 视频首期提供静态通用封面、文件信息和下载，不提供播放；后续可通过 `ffmpeg` 生成视频首帧。
- 上传后文件先进入「处理中」状态。处理期间允许移动、重命名和删除，但不允许预览、下载或创建分享。完成后自动刷新列表，并在应用内提示一次。
- 图片详情采用全屏查看，支持上一张、下一张、下载、分享和删除；不向普通用户展示扫描、队列等实现细节。
- 移动端的文件选择支持批量移入回收站和合并分享；图片全屏预览在底部明确展示分享、下载和删除操作。

### 3.4 上传、检索与回收站

- 同目录重名文件自动追加序号，不覆盖已有文件。
- 大文件上传保留服务端上传任务。浏览器通过 `localStorage` 保存文件指纹和任务 ID；重新选择名称、大小和最后修改时间均一致的文件时，提示继续或取消上传。
- 未完成上传任务的固定清理时间为 24 小时。
- 搜索覆盖文件名称，并提供图片、视频、其他类型及最近 7 天、最近 30 天、今年、更早等筛选。
- 回收站保留期为 30 天，并显示预计清理日期。手动永久删除后释放用户逻辑容量，并按分享规则撤销外部访问。

### 3.5 安全、隐私与运营

- 公开链接按 IP 限速：下载最多 20 次/分钟；密码连续错误 5 次后锁定该 IP 10 分钟。
- 审计只记录匿名化 IP、时间、token 和结果，不保存不必要的个人访问明细。
- 原始图片默认保留 EXIF。后续可提供「分享下载副本时移除定位信息」选项；在功能实现前不得宣传位置隐私保护。
- 前端仅展示用户可理解的状态和恢复操作。病毒扫描、对象存储、后台队列等技术细节保留在技术文档与运维说明中。

| 里程碑 | 目标 | 主要验收点 |

| M1：分享闭环 | 已完成公开页面、密码验证、登录下载、保存副本、计数和撤销规则。 | 未登录只能按规则预览；下载和保存要求登录；源文件与副本生命周期正确分离。 |

## 5. 系统边界

CloudBox 的后端应保持以下分层：

```text
Web / Mobile Client
        |
        v
Go API Service
        |--------------------|
        v                    v
Relational Database   Object Storage
```

- 数据库存储用户、权限、文件记录、分享、上传任务和后台任务等元数据。
- 对象存储保存文件字节、缩略图和临时分片。首期可以使用本地磁盘或 MinIO；后续可替换为企业 S3 兼容服务，而不改变业务接口。
- 应用服务负责鉴权、配额、分享策略、生命周期和异步任务调度。
- 不把对象存储的 bucket、路径、扫描结果或内部错误直接暴露给普通用户。
- 当前访问限速和密码失败计数保存在 API 进程内，适用于单实例部署。部署多个 API 实例前，应改用 Redis 等共享存储承载该状态。

## 6. 后续验收原则

- 先完成端到端用户流程，再扩展技术亮点；每项亮点必须对应可验证的用户价值或安全边界。
- 新增接口前先确认权限、配额、对象生命周期和失败恢复行为。
- 前端状态必须与后端真实能力对应。没有的接口和没有完成的策略不能通过静态文案伪装为已支持。
- 涉及删除、分享、容量、密码和管理员操作时，必须覆盖正常路径、越权路径、失败恢复和测试用例。
